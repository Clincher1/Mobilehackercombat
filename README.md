# HACKER KOMBAT — офлайн-версия в разработке

Отдельная одиночная версия для Android, основанная на `Clincher1/HACKCOMBAT` (коммит `7193c7917e07e13f0744026e53fb5a26dc2cde63`). Действующая Telegram-игра и её база не используются.

## Состояние

Игровые действия исполняются локально в браузере, без игрового сервера. Прогресс записывается в localStorage устройства, в профиле есть тестовый экспорт и импорт JSON-сохранения. Кнопка общего рейтинга убрана. Это пока **веб-прототип, а не готовый APK**: работа в Android WebView, скачивание/выбор файла, обновление приложения и сохранение между версиями ещё требуют реализации и проверки на телефоне. Браузерный предпросмотр сам по себе должен сначала загрузиться через сеть.

Данные могут быть потеряны при очистке данных, удалении приложения или отказе хранения. Резервный файл следует сохранить в отдельном месте. Не используйте настоящий прогресс или личные данные в тестовом прототипе. Не выпускать без полноценного тестирования и отдельного разрешения владельца.

## Локальный запуск

Требуется Node.js 22 и npm:

```bash
cd game
npm ci --ignore-scripts
npm run dev
```

Игровые расчёты выполняются на устройстве; Vite нужен лишь для загрузки прототипа в браузер. Для проверки:

```bash
npm run build
npm run qa:device   # локальное ядро, сохранение и повторная загрузка без сервера
npm run qa:offline  # исходные правила офлайн-копилки
npm run qa:sandbox  # проверки ограничений старого серверного тестового ядра
```

Изоляция: Supabase и Telegram-бот в этой копии принудительно отключены; реклама, маршруты донатов и рефералов выключены. Внутренний код ещё содержит наследуемые Telegram- и серверные компоненты, требующие дальнейшей очистки; не следует считать это законченным аудитом.

Первоначальный аудит: [docs/ANDROID-AUDIT-AND-PLAN.md](docs/ANDROID-AUDIT-AND-PLAN.md). Заметки по RuStore: [docs/RUSTORE-PRIVACY-RELEASE.md](docs/RUSTORE-PRIVACY-RELEASE.md); эти документы описывают первоначальный онлайн-план и должны быть пересмотрены для офлайн-выпуска.
